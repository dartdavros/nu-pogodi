# Ну, погоди! — две реализации

Две независимые браузерные реконструкции советской электронной игры «Электроника ИМ-02 — Ну, погоди!».
Обе сделаны на чистых HTML, CSS и JavaScript, графика — SVG, без Canvas, фреймворков и внешних зависимостей.
Каждую можно запустить, открыв её `index.html` в браузере.

| Папка | Играть онлайн |
|---|---|
| [`Opus/`](Opus/) | https://games.ermolaev.tech/nu-pogodi/opus5.5/index.html |
| [`Astro/`](Astro/) | https://games.ermolaev.tech/nu-pogodi/gpt6-astra/index.html |

Подробности об управлении, правилах и устройстве кода — в README каждой папки.
