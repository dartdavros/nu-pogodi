# Ну, погоди! / Электроника ИМ–02

Самостоятельная SVG-реконструкция карманной электронной игры. Статическое приложение: HTML, CSS и обычный JavaScript. Нет backend, пакетов, сетевых запросов, изображений, Canvas или сборщика.

## Запуск

Откройте `index.html` в современном браузере. Установка, сервер и интернет не нужны. Классические скрипты работают через `file://`.

Нажмите **START**. Управление реагирует на нажатие:

| Лоток | Клавиша |
| --- | --- |
| Верхний левый | Q |
| Нижний левый | A |
| Верхний правый | P |
| Нижний правый | L |

Используются физические позиции клавиш: русская раскладка также работает. **Esc** ставит игру на паузу и продолжает её. Enter / пробел запускают игру или продолжают паузу, если фокус не на другой кнопке. Звук можно выключить.

На сенсорном устройстве используйте четыре красные кнопки. Основной режим управления определяется возможностями указателя и касания, а не шириной окна. На телефоне игра доступна в горизонтальной ориентации. Поворот в вертикальную, уход со вкладки и потеря фокуса ставят игру на паузу; продолжение требует нажатия. Приложение не принуждает браузер к fullscreen или блокировке ориентации.

## Правила

- Пойманное яйцо: +1 к счёту. Обычный промах: 1 штраф.
- Заяц появляется на 5 секунд каждые 18 секунд, впервые на девятой секунде. При нём промах даёт ½ штрафа.
- При 3 или более штрафах игра заканчивается. Падение и разбитие последнего яйца показываются до экрана результата.
- На 200 и 500 все штрафы сбрасываются. Эти пороги повторяются после оборота счётчика.
- После 999 экран показывает 000, игра продолжается. Рекорд хранит полное количество пойманных яиц.
- Темп постепенно растёт; после каждой сотни есть небольшая передышка на 22 очка. Время движения уже появившегося яйца не меняется, минимальный интервал между прибытиями — 430 мс.
- Рекорд и настройка звука сохраняются в `localStorage`. Если браузер запрещает хранилище, рекорд доступен в памяти до закрытия страницы.

## Структура

- `js/mechanics.js` — независимое игровое состояние, шаги, очки, штрафы и сложность.
- `js/art.js`, `js/scene.js` — собственная векторная графика и сборка SVG-сцены.
- `js/display.js` — положение Волка, цифровой LCD, плавное перемещение яиц и эффекты.
- `js/controls.js` — клавиатура, Pointer Events, определение возможностей и ориентации.
- `js/audio.js` — короткие синтезированные сигналы Web Audio.
- `js/app.js` — связь модулей, жизненный цикл, пауза и сохранение рекорда.
- `styles/` — оформление корпуса, интерфейса и адаптация размеров.

Логика не читает SVG-координаты. Один `requestAnimationFrame` обслуживает всю страницу, включая повторные старты. На больших пропусках кадров игра ставится на паузу; отдельный шаг времени ограничен 100 мс. Анимация реализована изменением атрибутов настоящих SVG-объектов.

## Проверка

При наличии Node.js: `node --test tests/mechanics.test.cjs`.

Отдельная сборка не требуется. Для проверки синтаксиса: `Get-ChildItem js/*.js | ForEach-Object { node --check $_.FullName }` в PowerShell.

Браузерная проверка запускается напрямую через `file://`, без HTTP-сервера и заглушек. Скрипт `tests/browser.cjs` использует **внешнюю тестовую установку** Playwright из окружения разработчика; в приложении зависимости отсутствуют. Передайте путь к этой установке через `PLAYWRIGHT_MODULE`, при необходимости путь к браузеру через `BROWSER_PATH`, затем выполните `node tests/browser.cjs`.
