# Ну, погоди! — SVG-реконструкция «Электроника ИМ-02»

Откройте `index.html` в браузере — сборка и сервер не нужны.

## Управление

| Лоток          | Клавиши       | Touch                          |
|----------------|---------------|--------------------------------|
| верхний левый  | Q / 7         | левая верхняя кнопка / зона    |
| нижний левый   | A / 1         | левая нижняя кнопка / зона     |
| верхний правый | P / 9         | правая верхняя кнопка / зона   |
| нижний правый  | L / 3         | правая нижняя кнопка / зона    |

Стрелки переставляют Волка относительно текущего положения.
Enter — старт / продолжить, Пробел — старт / пауза, Esc — пауза, M — звук.

## Правила

- Поймано яйцо — +1 очко; счёт трёхзначный, после 999 идёт 000.
- Промах — 1 штраф, если в окне Заяц — ½ штрафа. 3 штрафа — конец игры.
- На 200 и 500 очках штрафы сбрасываются.
- Скорость и частота яиц растут; после каждой сотни темп ненадолго снижается.

## Структура

- `js/engine.js` — игровая механика без DOM (состояние, такты, штрафы в половинках).
- `js/view.js` — SVG-сцена: Волк, лотки, яйца, Заяц, табло, анимации.
- `js/input.js` — клавиатура и Pointer Events.
- `js/audio.js` — звуки через Web Audio API.
- `js/main.js` — игровой цикл, ориентация, рекорд (localStorage).
- `tests/engine.test.js` — проверка правил: `node tests/engine.test.js`.
